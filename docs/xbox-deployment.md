# Xbox Developer Mode build and installation

## Target

The project builds a UWP x64 APPX. The manifest Publisher is CN=Xmana Development and the package identity is space.karrarnazim.Xmana.

## Automated signing

The GitHub Actions workflow builds an unsigned sideload package, creates a short-lived self-signed code-signing certificate with a Subject matching the manifest Publisher, signs the APPX with SignTool using SHA-256, verifies the signature and deletes the private PFX and temporary certificate from the runner. The artifact includes only the public .cer.

Each workflow run creates a different development certificate. The .cer is paired only with the package from that run. Download and keep both files from the same workflow artifact.

## Install on Xbox

1. Switch the console to Developer Mode and sign in to a user profile.
2. Open Xbox Device Portal from a browser on the same network.
3. Open Apps → Deploy apps.
4. Select the APPX generated by that workflow run.
5. Select Xmana-Dev-Certificate.cer in the certificate selector.
6. Deploy/install the package.

The device must trust the certificate used to sign the package. Do not use a certificate from another workflow run.

## Manual Visual Studio build

Open Xmana.sln, select Release | x64 and create a sideload package. Do not commit a PFX, private key or signing password.

## Validation

The workflow can validate compilation, package creation, signature creation and signature verification. It cannot prove runtime playback or controller behavior on physical Xbox hardware. Those still require installation and device testing.
